# Hexadecimal Converter (C++)

## About the Project
This is a simple C++ console-based program that converts hexadecimal numbers into different number systems.

It is designed to help beginners understand number system conversions using basic C++ programming concepts.

## Features
- Hexadecimal to Decimal Conversion
- Decimal to ASCII Conversion
- Decimal to Binary Conversion
- Decimal to Octal Conversion
- Supports uppercase and lowercase hexadecimal letters
- Supports `0x` and `0X` prefixes
- Checks invalid hexadecimal characters
- Allows continuous input until the user enters `q` to quit

## Technologies Used
- C++
- iostream
- Arrays
- Loops
- Conditional Statements

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/zeshanmain555-byte/Hexadecimal-Converter.git
```

**2. Open the project folder**

```bash
cd Hexadecimal-Converter
```

**3. Compile the program**

```bash
g++ main.cpp -o converter
```

**4. Run the program**

```bash
./converter
```

## Example

```text
Enter a hexadecimal number: 41

Decimal : 65
ASCII   : A
```
